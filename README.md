## 📄 About Project

This Project is my personal portfolio, designed to centralize and present my projects, habilities and contact information in a modern and accessible way. It was build from the ground up, applying responsive design and best web development practices to ensure a great experience on any device.

---

## ✨ Features

- **Responsive Design**: Fully adaptable for desktops, tablets and smartphones.
- **Projects Gallery**: A section dedicated to present my most relevant projects, with links to demo, repository and preview.
- **Animation and Transitions**: Smooth transition and animation.
- **Get in Touch formulary**: An easy way to get in touch with me.
- **Social Links**: Quick access to LinkedIn, GitHub and other networks.

## 🚀 How to run the project

It is an static front-end project, you can run locally.

1.  **Clone the repository:**
    ```bash
    git clone https://github.com/ReinaldoJunior3108/MeuPortfolio.git
    ```
2.  **Go to the directory:**
    ```bash
    cd MeuPortfolio
    ```
3.  **Open file `index.html`:**
    - Just open `index.html` on your favorite browser.
